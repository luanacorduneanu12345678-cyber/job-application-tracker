# 💼 Job Application Tracker

A responsive web application for organizing and tracking job applications throughout the recruitment process.

Built with **Next.js, React, TypeScript, and Tailwind CSS**.

## ✨ Features

- **Application Management:** Add, edit, and delete job applications.
- **Status Tracking:** Track applications as Applied, Interview, Offer, or Rejected.
- **Dashboard:** View total applications, interviews, and offers.
- **Search:** Find applications by company name or job position.
- **Filtering:** Filter applications by recruitment status.
- **Date Validation:** Enter and validate application dates.
- **Local Storage:** Automatically save applications in the browser.
- **Responsive Design:** Use the application on desktop and mobile devices.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/luanacorduneanu12345678-cyber/job-application-tracker.git
```

Navigate to the project directory:

```bash
cd job-application-tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## 📖 How It Works

Users can create job application entries by entering a company name, job position, and application date.

Each application can be updated or deleted. The dashboard automatically calculates statistics based on the current applications.

Search and filtering help users manage their applications efficiently.

Application data is stored in the browser using `localStorage`, allowing it to persist after refreshing the page.

**Note:** Data is stored locally and is not synchronized between browsers or devices.
